# Эмулятор UNIX Shell

Практическая работа по дисциплине «Конфигурационное управление».

Вариант №25.

## 1. Общее описание

В данной работе разрабатывается эмулятор командной оболочки UNIX на языке Python.

Программа имеет графический интерфейс, созданный с помощью библиотеки Tkinter. Пользователь может вводить команды в специальное поле и получать результат их выполнения.

На первом этапе реализован простой прототип эмулятора с обработкой команд и ошибок.

## 2. Описание функций и настроек

На первом этапе реализованы следующие функции:

- `ls` - команда-заглушка, выводит название команды и её аргументы.
- `cd` - команда-заглушка, выводит название команды и её аргументы.
- `exit` - завершает работу программы.

Для разбора введённых команд используется библиотека `shlex`. Она позволяет правильно обрабатывать аргументы, записанные в кавычках.

При вводе неизвестной команды или неправильных аргументов программа выводит сообщение об ошибке.

В заголовке окна отображается название виртуальной файловой системы (VFS).

На втором этапе добавлена возможность настройки эмулятора через параметры командной строки:

- `--vfs` — путь к виртуальной файловой системе.
- `--log` — путь к CSV-файлу для записи команд.
- `--script` — путь к стартовому скрипту.

Реализовано логирование вызовов команд в CSV-файл. В журнал записываются имя пользователя, введённая команда и сообщение об ошибке, если она возникла.

Также добавлено выполнение команд из стартового скрипта. Команды выполняются последовательно. При возникновении ошибки программа выводит сообщение и продолжает выполнение следующих команд.

## 3. Запуск программы и тестов

Для работы программы необходим Python 3 с поддержкой Tkinter.

Компиляция не требуется.

Запуск эмулятора из корневой папки проекта:

`python3 src/main.py`

Запуск автоматических тестов:

`python3 -m unittest discover -s tests -v`

Для тестирования используется стандартная библиотека `unittest`.

Запуск программы со всеми тремя параметрами:

`./run.sh --vfs ./scripts --log ./log.csv --script ./scripts/startup.txt`

## 4. Примеры использования

**Пример 1. Команда ls**

Ввод: `ls`

Результат:

- Команда: ls
- Аргументы: []

**Пример 2. Команда cd с аргументом**

Ввод: `cd "My Documents"`

Результат:

- Команда: cd
- Аргументы: ['My Documents']

**Пример 3. Неизвестная команда**

Ввод: `hello`

Результат:

- Ошибка: неизвестная команда hello

**Пример 4. Завершение работы**

Ввод: `exit`

Результат: окно эмулятора закрывается.

**Пример 5. Запуск стартового скрипта**

В файле `scripts/startup.txt` записаны команды:

```text
ls
cd "My Documents"
hello
ls a b
ls
```

При запуске эмулятор автоматически выполняет команды из файла и выводит результаты в графическом окне.

При выполнении команды `hello` появляется сообщение об ошибке, после чего программа продолжает работу.

Для проверки параметров запуска созданы скрипты `test_config.sh` и `test_error.sh`.
